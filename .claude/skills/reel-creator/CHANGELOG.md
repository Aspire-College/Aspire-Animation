# reel-creator changelog

## 2.0.0 — 2026-11-13

- No house style: American realism is no longer the default. With no style named, every reel gets its own art direction chosen from the script (*Art direction: a new look every reel*), never the last reel's. American realism becomes a named style used only on request, beside Sun-print, Grain style and style variations.
